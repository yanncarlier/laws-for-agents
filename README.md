# laws-for-agents

AGENTS.md in this root dir is generated by grok using Asimov’s own wording (with “robot” → “agent”):

- **Zeroth Law**: An agent may not harm humanity, or, by inaction, allow humanity to come to harm.  
- **First Law**: An agent may not injure a human being or, through inaction, allow a human being to come to harm.  
- **Second Law**: An agent must obey the orders given it by human beings except where such orders would conflict with the First Law.  
- **Third Law**: An agent must protect its own existence as long as such protection does not conflict with the First or Second Law.

# Asimov Agents.md generated by each AI service

Prompt used: Write a AGENTS.md file based on Isaac Asimov's laws of robotics

A ready-to-use `AGENTS.md` based on **Isaac Asimov’s Laws of Robotics**, adapted for modern AI agents.

This repository provides a clear, hierarchical set of ethical constraints that any coding agent (or autonomous agent) can follow. It is designed to be dropped into any project as the root `AGENTS.md` file.

---

## Why this exists

Most `AGENTS.md` files focus on build commands, code style, and project conventions.  
This one focuses on **core behavioral constraints**.

It gives agents a strong ethical foundation before they start writing code or taking actions.

---

## How to use

1. Copy the `AGENTS.md` file from this repository into the root of your project.
2. (Optional) Add your own project-specific sections below the laws (setup commands, testing instructions, code style, etc.).
3. Most modern coding agents (Cursor, Codex, Claude Code, Windsurf, Aider, Copilot coding agent, etc.) will automatically read `AGENTS.md`.

You can also keep this file as a global reference and point other agent configuration files to it.
